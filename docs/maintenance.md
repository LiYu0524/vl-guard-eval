# 维护与追加结果

1. 对新模型固定 checkpoint／provider model ID、模板、返回格式、generation 参数及参考标签版本。使用同一 cohort 与选中调用才能直接比较。
2. 完成推理和错误收尾后，保留每次正式 attempt。未知、错误及未评测状态单独记账。
3. 公开导出使用固定匿名 cohort ID。追加模型时使用本地保留的映射；也可按同一冻结 cohort 行序和 case 排序重建，随后验证原 9,180 条对应关系。映射保留在本地，不提交到公开仓库。
4. 将新结果放入独立的 `predictions/<date>/` 与 `results/<date>/`，保留旧版本。模型或标签口径变化在对应 manifest 和报告中明确说明。
5. 重算 ACC、覆盖率、混淆矩阵和配对比较，更新首页。AgentDoG 1.5 当前状态为未评测，不能用准备检查或服务探测生成分数。
6. 上传前运行统计复现与测试，检查文件中没有原始轨迹、回答正文、私有路径或凭据。CI 只做本地统计与测试，不调用模型 API。

参考标签若人工修订，应创建新的标签版本与结果目录，保留原机器标注结果。日期目录与首页中的完成状态按实际执行记录更新。
